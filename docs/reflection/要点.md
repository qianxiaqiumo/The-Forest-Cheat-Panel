# GitHub 参考资料要点

## 1. Hellsing/ModAPI-Mods

https://github.com/Hellsing/ModAPI-Mods

### PlayerStats 字段（上帝模式里被逐帧覆写）

`GriefClientPro/Overwrites/PlayerStatsEx.cs`：

```csharp
protected override void Update()
{
    if (Menu.Values.Self.GodMode)
    {
        IsBloody = false;
        FireWarmth = true;
        SunWarmth = true;
        IsCold = false;
        Health = 100f;
        Armor = 400;
        Fullness = 1f;
        Stamina = 100f;
        Energy = 100f;
        Hunger = 0;
        Thirst = 0;
        Starvation = 0;
    }
    base.Update();
}
```

判定范围（同一项目 `Menu.cs`）：

| 字段 | 界面滑块范围 |
|---|---|
| Health | 0 ~ 100 |
| BatteryCharge | 0 ~ 100 |
| Fullness | **0 ~ 1** |
| Stamina | 0 ~ 100 |
| Energy | 0 ~ 100 |
| Thirst | **0 ~ 1** |
| Starvation | 0 ~ 1 |
| BodyTemp | 10 ~ 60 |

> 注意：`0Z0F/TheForestMod` 里写的是 `Fullness = 100f`，说明**不同版本单位不同**，
> 所以我们的实现按"当前值 ≤1.5 就当作 0~1 制"自动判断。

## 2. 0xZ0F/TheForestMod

https://github.com/0xZ0F/TheForestMod

最小可用结构（Harmony + Mono 注入）：

```csharp
// 入口
var harmony = HarmonyInstance.Create("com.z0f.TheForestMod");
harmony.PatchAll(Assembly.GetExecutingAssembly());
cheatObject = new GameObject();
cheatObject.AddComponent<Manager>();
DontDestroyOnLoad(cheatObject);

// 每帧补属性
[HarmonyPatch(typeof(PlayerStats)), HarmonyPatch("Update")]
class PlayerStats_Patch
{
    static void Postfix(PlayerStats __instance)
    {
        if (Manager.enabled_GodMode)
        {
            __instance.Health = 100f;
            __instance.Energy = 100f;
            __instance.Stamina = 100f;
            __instance.Fullness = 100f;
            __instance.Thirst = 0f;
            __instance.Sanity.CurrentSanity = 100f;
        }
    }
}
```

- 传送：`LocalPlayer.Rigidbody.velocity = Vector3.zero; LocalPlayer.Transform.position = 目标;`
- 菜单：IMGUI（`OnGUI` + `GUI.Toggle/Button`），F5/F7 开关

## 3. 结论

| 结论 | 说明 |
|---|---|
| 不要扫内存 | 这类游戏的属性/物品是托管对象，地址不稳定；直接调游戏对象最稳 |
| 属性名可靠 | 两个独立项目字段名一致（Health/Stamina/Energy/Fullness/Thirst/Starvation） |
| 单位要自适应 | Fullness/Thirst 有 0~1 与 0~100 两种写法，必须按当前值判断 |
| 物品生成需要实测 | 两个参考项目都没给出 `ItemHolder` 的具体 API，需要游戏装好后反射探测 |
